## Web console

On the server's screen: **F2 › Reset web admin password**, choose the user, and enter a new password. The user is signed out everywhere.

## The `vbase` account

On the server's screen: **F2 › Reset `vbase` OS password**.

## A database's admin password

In the web console, open the database and choose **Reset admin password**. The new one is shown once; the old one stops working.

:::note
Both server resets need someone at the server's screen. That's deliberate: being at the server already means full control of it.
:::
